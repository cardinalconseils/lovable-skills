# lovable-skills

A comprehensive skills library for [Lovable.dev](https://lovable.dev) — expert knowledge across engineering, product, marketing, strategy, and AI.

Each skill is a `SKILL.md` file that Claude loads on demand when the matching topic is detected.

## How to Import

In your Lovable project, import any skill via its GitHub URL:

```
https://github.com/cardinalconseils/lovable-skills/tree/main/{skill-name}
```

Example:
```
https://github.com/cardinalconseils/lovable-skills/tree/main/authentication
```
